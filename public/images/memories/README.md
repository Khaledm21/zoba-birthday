# مجلد صور الذكريات — Memories Photo Folder 📸

هنا يمكنك وضع صورك الحقيقية مع «زوبا» بكل سهولة وسيقوم الموقع بعرضها تلقائياً وبأعلى جودة!

## أسماء الملفات المدعومة:
- `memory-01.jpg` (أول ذكرى في الكاروسيل ثلاثي الأبعاد)
- `memory-02.jpg` (ثاني ذكرى)
- `memory-03.jpg` (ثالث ذكرى)
- `memory-04.jpg` (رابع ذكرى)
- `memory-05.jpg` (خامس ذكرى)
- `memory-06.jpg` (سادس ذكرى)

## ملاحظات:
1. يدعم الموقع صيغ JPG أو PNG أو WEBP.
2. إذا أردت تعديل العناوين والنصوص والتواريخ المكتوبة تحت كل صورة، يمكنك تعديل ملف:
   `src/data/memories.ts`
3. في حال لم تكن الصور متوفرة حالياً، الموقع يعرض تصاميم فنية راقية كـ Placeholders بديلة بدون أي Broken Images!
