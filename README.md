# A Little Birthday Magic — For Zoba 🎂✨

موقع احتفالي سينمائي فاخر مصمم ومبني بالكامل من الصفر خصيصاً لـ **«زوبا» (زينب)** بمناسبة عيد ميلادها.

---

## ✨ المميزات الرئيسية للمشروع

1. **المشهد الافتتاحي (Cinematic Hero):**
   - خلفية ليلية سينمائية بلوني `Midnight Navy` و `Deep Violet` مع نجوم متحركة وتأثيرات Bokeh ناعمة.
   - عنوان رئيسي وتدرجات ألوان ذهبية وبنفسجية أنيقة.
   - زر تفاعلي ينطلق بانتقال سلس نحو المفاجأة.

2. **صندوق الهدايا التفاعلي ثلاثي الأبعاد (Interactive 3D Gift Box):**
   - تصميم 3D حقيقي للشريط والغطاء والظل الواقعي.
   - تفاعل عند اللمس أو النقر يفتح الغطاء وتنبثق منه أضواء ذهبية وقصاصات ورق (Confetti).
   - كشف الرسالة السرية: *“Something special is waiting for you…”* وزر للانتقال إلى الرسالة.

3. **رسالة عيد الميلاد الشخصية (Personal Birthday Letter):**
   - بطاقة ورقية بملمس ناعم وظلال واقعية وختم شمعي أحمر أنيق (*FOR ZOBA*).
   - ظهور تدريجي للنص بطريقة Typewriter / Staggered Reveal.
   - خيار "تخطي الحركة" (Skip Animation) أو "إعادة العرض" (Replay).
   - نص أصلي دافئ وودود باللغتين العربية والإنجليزية.

4. **عالمنا الصغير (Our Little Universe — 3D Photo Carousel):**
   - **القطعة الفنية الأبرز:** معرض صور أسطواني دائري ثلاثي الأبعاد حقيقي (`perspective`, `rotateY`, `translateZ`, `preserve-3d`).
   - دوران تلقائي بطيء يتوقف عند التمرير أو التفاعل.
   - تنقل باللمس والسحب (Swipe/Drag)، وأزرار الأسهم، ولوحة المفاتيح.
   - إضاءة وظلال وعمق لكل صورة، مع إمكانية فتح أي صورة في وضع السينما.

5. **معرض صور بولارويد العائمة (Floating Polaroid Gallery):**
   - بطاقات صور بإطارات بولارويد كلاسيكية مع زوايا ميلان فنية غير متماثلة.
   - شريط لاصق واشي (Washi tape) وزخارف دقيقة.
   - ترتفع الصورة وتعتدل عمودياً عند التمرير عليها (Hover Lift & Straighten).

6. **نافذة العرض السينمائي المكبر (Cinematic Lightbox):**
   - خلفية مظلمة شفافة مع `backdrop-blur`.
   - تنقل كامل بالأسهم، وزر الإغلاق، ودعم زر `Esc`، وقفل تمرير الصفحة خلفها.

7. **خط زمني تفاعلي للذكريات (Moments Timeline):**
   - 4 محطات دافئة تحكي لحظات جميلة مع أيقونات معبرة وظهور متناسق.

8. **كعكة عيد الميلاد والشموع التفاعلية (Interactive Birthday Cake):**
   - كعكة بطبقات ملونة وتفاصيل كريمة وحبيبات زينة.
   - شموع مضيئة بلهب متحرك.
   - إطفاء الشموع بالضغط أو اختياريًا عبر الميكروفون عند النفخ (بإذن المستخدم الصريح دون إزعاج).
   - ظهور دخان لطيف وقصاصات ضوئية عند انطفاء الشموع مع عبارة: *“Wish made? 💫”*.

9. **الاحتفال النهائي المبهج (Birthday Celebration Finale):**
   - مفرقعات Confetti احتفالية مزدوجة.
   - رسالة ختامية مؤثرة.
   - زر "Replay the Magic" لإعادة خوض التجربة من البداية وتصفير الحالة بسلاسة.
   - زر العودة إلى الذكريات.

10. **دعم حقيقي للغات (Trilingual Experience):**
    - العربية (RTL كامل مع خط Cairo الأنيق).
    - الإنجليزية (LTR مع DM Sans و Playfair Display).
    - كلاهما معاً (Both Languages) لعرض لغوي مزدوج فاخر.
    - حفظ التفضيل تلقائياً في `localStorage`.

11. **مشغل موسيقى هادئ وذكي (Ambient Music Player):**
    - زر تشغيل/إيقاف وتحكم بمستوى الصوت.
    - تشغيل ذاتي محظور تجنباً للإزعاج.
    - تشغيل ملف `public/audio/birthday-music.mp3` عند توفره، أو توليد لحن موسيقي هادئ (Music Box) باستخدام Web Audio API كبديل فوري في حال لم تتم إضافة ملف خارجي بعد!

## 📁 أين تضع الصور الشخصية والموسيقى؟

### 1. صور الذكريات:
ضع الصور داخل المجلد:
`public/images/memories/`

بالأسماء التالية:
- `memory-01.jpg`
- `memory-02.jpg`
- `memory-03.jpg`
- `memory-04.jpg`
- `memory-05.jpg`
- `memory-06.jpg`

> 💡 **ملاحظة:** تم تزويد المشروع بـ 6 تصميمات بديلة متقنة وفنية حتى لا تظهر أي Broken Images في حال لم تكن الصور مضافة بعد!

### 2. الموسيقى:
يمكنك وضع ملف الموسيقى المفضل في:
`public/audio/birthday-music.mp3`

### 3. تعديل النصوص والذكريات:
- لتعديل نصوص الرسالة: `src/data/letter.ts`
- لتعديل عناوين وتفاصيل الذكريات: `src/data/memories.ts`
- لتعديل المحطات: `src/data/timeline.ts`
- لتعديل جميع واجهات التطبيق: `src/i18n/translations.ts`
